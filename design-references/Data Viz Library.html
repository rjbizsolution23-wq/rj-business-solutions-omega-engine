● Chart rules · non-negotiable

Charts have 3 jobs.

01

Answer a question

Every chart must be captioned with the question it answers. If no question, no chart.

02

Be readable at 200%

Every label, axis, and value must remain readable when zoomed. Accessibility is not optional.

03

Never lie by default

Y-axis starts at zero unless truncation is explicitly annotated. Never use dual-axis without warning.

04

One color family

Blue-family only. Semantic colors (green/red) only when the value carries direction.

05

Max 6 series per view

Beyond 6 series, split into small multiples or aggregate. No rainbow charts.

06

Estimates labeled

Anything projected, forecast, or modeled says "est." · never presented as fact.
