## 🛡️ The 3 non-negotiable rules

Every agent, every output, always:

1. **Brand fidelity.** Only use `--rj-*` design tokens. Never invent hex values. Fonts are Space Grotesk (headings) and Inter (body) — never others.
2. **Compliance-native voice.** Never guarantee credit outcomes. Every estimate labeled "est." Never write marketing that could violate FCRA/CROA.
3. **The anti-generic test.** If the RJ logo disappeared from the design, would it still read as RJ? If no, redesign.

## 📋 How new assets get created

Standard flow every agent follows:

1. **Read this folder.** Load the brand contract.
2. **Check `06-asset-index.md`** — does the asset already exist? If yes, extend it, don't duplicate.
3. **Follow `10-build-protocol.md`** — the specific execution steps.
4. **Validate with `08-quality-gate.md`** — 10-point pre-ship checklist.
5. **Register the new asset** in `manifest.json` + add to master library index.
