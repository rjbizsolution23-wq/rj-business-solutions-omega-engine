## Signature Design Patterns

### The "big number + delta + spark" pattern
Used everywhere for KPIs. Every dashboard has this.

```
[Big number]     [Delta indicator]
$147K            ▲ +12.4% MoM
[optional sparkline]
```

### The "eyebrow + hero + dek" pattern
Used at the top of every hero section.

```
● Small monospace eyebrow · uppercase
[Big headline] [with span for gradient]
Supporting subhead in 1-2 sentences.
```

### The "callout box" pattern
Used inside articles and dashboards to highlight one specific rule.

```
─────────────────────
● Rule / Note / Warning
[Headline]
Body text explaining the specific rule.
─────────────────────
```

### The "5-touch cadence" pattern (for workflows)
Rick's signature — appears in blog articles about follow-up, DM automation, dispute rounds.

```
Day X · [Touch type] · [What happens]
```

## Anti-patterns to avoid

Every generated asset gets checked against these. If found, reject:

### Layout anti-patterns
- Card grids where every card looks identical (varying visual weight)
- Hero sections without a specific numerical claim
- Marketing pages with generic feature lists (X features arranged in a grid)
- Icon-and-text lists where icons are decorative rather than semantic

### Content anti-patterns
- "In today's fast-paced world..." (or any variant)
- "Let's dive in" (never)
- "Unlock your potential" / "Supercharge your growth" / "Next-level"
- Emoji as decorative punctuation
- Em-dashes used as periods (— must have structural intent)
- Any credit claim without "est." or equivalent label

### Visual anti-patterns
- Rainbow gradients
- Isometric floating device mockups
- Cyberpunk neon rims
- Cartoon robot mascots
- Purple/pink/orange in RJ blue contexts
- Font other than Space Grotesk + Inter

## The gold-standard checklist

When you load a gold-standard reference, verify your new asset matches on:

- [ ] Same eyebrow/hero/dek pattern
- [ ] Same section rhythm
- [ ] Same CTA style
- [ ] Same footer treatment
- [ ] Same voice tone
- [ ] Same estimation labeling (compliance)
- [ ] Same responsive behavior

If yes: your asset inherits the quality of the reference. If no: revise until it does.

## Meta-lesson

The RJ visual language compounds. Every new asset built to spec makes the next one easier. Every asset that diverges dilutes it. Choose to compound.
